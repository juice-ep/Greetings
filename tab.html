⚠️ No workstation PC — what this means for AutoCAD
AutoCAD Mobile (free)
View, pan, zoom, layer toggle — works on all tablets below. Perfect for site review.
AutoCAD Mobile Premium (₹3,500–5,000/yr)
Basic editing: move/copy objects, dimensions, hatch, basic blocks. Covers 'occasional' edits.
AutoCAD Web (browser)
Closer to desktop — runs in Chrome on any tablet. Needs WiFi but handles more complex edits.
Laptop still needed IF
Creating drawings from scratch, plotting at exact scale, using custom LISP routines, or managing complex layer sets.
For a project head reviewing drawings on site and annotating — a tablet is sufficient. For creating drawings from scratch, a Windows laptop remains necessary.
💻 Still need a laptop?
If AutoCAD editing ever goes beyond basic annotation — creating new drawings, complex edits, printing to exact scale — the laptop list applies. The ASUS Vivobook Flip (~₹93k) or HP OmniBook 5 fp0790TU (~₹75k) remain the top picks. A tablet + budget laptop is often more practical than one expensive 2-in-1.
